```markdown
## 电量中枢 PowerHub v1.9.0

一次以「看得清、点得准、位置稳」为目标的界面精修，同时清掉了设置页里一个只用于测试的开关。
**本版没有改动设备协议**，升级不需要迁移配置；`dist/` 里的历史版本也一个没删。

### 新增与改进

- **主页面头部品牌化**：左上角「电量中心」更正为「电量中枢」，旁边并列英文名 `PowerHub`
  与版本胶囊 `v1.9.0`。版本号取自 `APP_VERSION` 常量，不再写死在界面里。
- **托盘电量数字严格居中**：改用字形墨迹包围盒对齐徽标中心，修掉了 `drawText(AlignCenter)`
  按整行行高居中导致的纵向偏低 1~2px（数字没有降部）。
- **面板每次打开都落在主屏右下角**：不再停在上次关闭的位置；即使手动拖到别处，
  收起后再打开也会回位。面板已经开着时点托盘菜单不会被强行拽回。
- **「全部已连接」状态更易读**：原来是浅绿字压浅绿底（对比度仅 1.59:1，白底也只有 1.29:1），
  改为灰胶囊 + 深绿圆点 `#12734A`（图形元素 4.08:1 / 3.30:1），文字回到深灰（6.13 / 4.95）。
- **拖动手柄的 6 个圆点严格等距**：原来是 4.5px / 4.0px 的上疏下密，
  现在是整数栅格 4 / 4、上下留白 7 / 7，并保持抗锯齿圆点观感。

### 修复

- 收起时停在设置页、下次打开面板悬在半空（下边距 222px）；点齿轮进设置再返回同样会悬空。
  现在切页前后锁住下边缘，展开方向始终贴着任务栏。
- 版本胶囊与页脚状态胶囊的对比度不足：在玻璃最暗角只有 4.06:1，数学上无法靠透明度达标；
  字色加深到 `#4A4A4F` 后达到 6.13 / 4.95。
- 设置页删除「演示数据」开关：正式使用时无用。命令行 `--demo` 与页脚「演示数据」标记保留，
  老配置里残留的 `demo: true` 在加载时会被忽略，不会再让软件莫名进入演示模式。
- 测试环境的假绿与假红：字体夹具改为按需注入（缺字体时不再整模块静默 SKIP）、
  补上 `QApplication` 兜底（没有它 Qt 会直接 abort 进程）、`pytest.ini` 固定
  `--basetemp=.pytest-tmp` 绕开本机损坏的临时目录链接。

### 工程

- 测试从 400 项增加到 **478 passed / 1 skipped**（39 个测试文件 / 479 项）；
  关键断言都配了「改回旧实现必红」的反向自证，不是只测控件矩形。
- 版本号只有 `app/core/paths.py: APP_VERSION` 一个来源，
  `tools/build_exe.py` 的产物名由它拼出，并有 AST 级护栏防止再写死版本字面量。
- 打包产物为单文件 exe，未做代码签名；首次运行若出现 SmartScreen 提示属正常。

这三项都不影响使用，计划后续单独处理。
```

## 发布操作（手动）

1. 打开 `https://github.com/Yi-One1/PowerHub/releases/new`。
2. **Tag**：填 `v1.9.0`，target 选 `main`（若本地提交尚未推送，先按 `progress.md` 的手动推送教程推上去）。
3. **Release title**：填上面的标题。
4. **正文**：复制上面「Release notes」代码块里的内容（不含最外层 ``` 围栏）。
5. **Attach binaries**：上传 `dist/电量中枢_PowerHub_v1.9.0.exe`（45,941,141 字节）。
6. 勾选 `Set as the latest release`，点 `Publish release`。
7. 发布后核对资产 SHA-256 与上表一致（本机 `sha256sum dist/电量中枢_PowerHub_v1.9.0.exe`）。
